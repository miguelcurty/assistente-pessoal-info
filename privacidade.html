Política de Privacidade

Última atualização: 09 de novembro de 2026.

Este aplicativo é de uso estritamente pessoal. Não é oferecido a terceiros, não tem base de usuários além do próprio desenvolvedor (Miguel Curty) e não tem fins comerciais.

O que o aplicativo acessa

Com autorização explícita via OAuth do Google, o aplicativo pode acessar, na conta Google do próprio dono: Gmail (leitura e envio de e-mail), Google Calendar (agenda), Google Drive, Planilhas Google e Documentos Google.

Como os dados são usados

Todo o processamento ocorre localmente, na própria máquina do dono, através da ferramenta de assistente pessoal Hermes Agent. Os dados acessados são usados exclusivamente para automatizar tarefas pessoais do próprio dono (organizar agenda, triar e-mail, acompanhar documentos pessoais). Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de terceiros.

Armazenamento

O token de acesso OAuth é armazenado localmente, de forma criptografada no sistema de arquivos do próprio computador do dono, com permissão restrita (leitura só pelo próprio usuário). Nenhuma cópia é enviada para servidores externos além das chamadas diretas às APIs oficiais do Google necessárias para o funcionamento do assistente.

Revogação de acesso

O acesso pode ser revogado a qualquer momento pelo próprio dono, em myaccount.google.com/permissions.
